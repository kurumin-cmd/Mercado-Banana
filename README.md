# Mercado Banana 🍌

Esse é um projeto que fiz para praticar e aprender mais sobre Python. Ainda quero melhorar bastante coisa nele, mas decidi postar aqui para acompanhar minha evolução.

Se tiver alguma dica ou sugestão, pode falar!

## Como funciona?

Quando você abre o programa, aparece um menu com três opções:
- Fazer login
- Fazer cadastro
- Sair

Se ainda não tiver uma conta, você pode se cadastrar informando seu nome, idade e senha. Os dados ficam salvos em um banco de dados SQLite, e a senha é protegida usando Argon2.

Depois de fazer login, você entra no menu do mercado, onde pode:

1. Ver os produtos disponíveis.
2. Comprar produtos.
3. Ver o carrinho.
4. Ver suas compras.
5. Sair e voltar para o menu inicial.

## Tecnologias usadas

- Python
- SQLite3
- Argon2
